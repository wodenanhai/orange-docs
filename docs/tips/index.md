## 小技巧

### 端口号被占用（macOS）

当你启动项目时遇到 `EADDRINUSE`，说明端口已被其他进程占用。

#### 方案一：查看并结束占用进程

```bash
# 1) 查看是谁占用了 8080 端口
lsof -i :8080

# 2) 结束对应 PID（把 1234 替换成上一步查到的 PID）
kill -9 1234
```

> `kill -9` 会强制终止进程，适合进程无法正常退出时使用。

#### 方案二：直接一条命令释放端口

```bash
lsof -ti :8080 | xargs kill -9
```

#### 方案三：换一个端口启动（推荐开发时使用）

```bash
npm run docs:dev -- --port 8081
```

```bash

```
