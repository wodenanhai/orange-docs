## 推荐学习路径

::: tip 三步完成知识闭环
先用面试专题建立知识框架，再通过手写实现补齐原理，最后用 Node 实战把能力落到项目中。
:::

1. **面试冲刺**：从 Vue2、Vue3、Webpack、HTML 和综合专题开始，快速定位高频考点。
2. **源码手写**：进入工具函数库，系统练习常见 API、异步方案与事件模型。
3. **项目落地**：沿着 Node 实战路线完成服务端、数据库与接口设计能力补齐。
