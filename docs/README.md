## 推荐学习路径

> 「今天背八股，明天改简历，后天拿 Offer」

::: tip 三步完成知识闭环
先用面试专题建立知识框架，再通过手写实现补齐原理，最后用 Node 实战把能力落到项目中。
:::

1. **面试暴击阶段**：先横扫 Vue2、Vue3、Webpack、HTML 与综合专题，建立“高频题雷达”。
2. **手写硬核阶段**：进入手写斗技场，用 API / 异步 / 事件模型把底层能力焊死。
3. **实战封神阶段**：沿 Node 实战路线把服务端、数据库、接口设计一条龙打通。
